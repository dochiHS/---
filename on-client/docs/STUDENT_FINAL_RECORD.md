# 모몽강 총공세 7일차: 완성본 시연 순서와 확인 범위

이 문서는 모몽강 완성본을 처음부터 끝까지 시연하는 순서를 정하고, 되는 것과 안 되는 것, 그 근거를 정리합니다. 근거는 두 가지만 씁니다. 하나는 이 문서를 쓰면서 코드와 문서를 읽어 확인한 내용이고, 다른 하나는 학생이 직접 확인했다고 진술한 내용입니다. 이 문서 작성자는 앱 실행, npm 명령, 포장 도구, 외부 네트워크 요청을 하지 않았습니다. 2026-10-28에 학생이 앱을 직접 실행해 시연 순서대로 확인한 화면(캡처 6장)을 학생이 보내 주어, 그 내용을 아래 표에 반영했습니다. 확인하지 못한 내용은 「미확인」으로 쓰고 이유를 적었습니다.

## 1. 핵심 기능 세 가지와 시연 순서

시연은 5분 안쪽을 목표로 합니다. 시연 전에 앱을 켜 두고, 계정 연결과 AI 연결이 끝난 상태에서 시작합니다. 계정 연결 절차는 시연 중에 다시 하지 않고 말로만 설명합니다. 확인 번호와 승인 화면에는 개인 정보가 보일 수 있기 때문입니다.

### 기능 ① 모몽강 관제 대시보드 (약 2분)

| 누를 곳 | 화면에서 보여 줄 것 | 말할 한 문장 |
|---|---|---|
| 앱을 연 직후, 보호 현황의 첫 학생 칸 맨 위 | 「모몽강 관제 대시보드」 제목, 「마지막 조회 시각」 문구, 상태 요약(고리 그래프와 주의·확인 불가·측정됨 등 점과 글자의 개수) | 앱을 열면 한 번만 읽고, 그 뒤에는 제가 누를 때만 읽습니다. 고리는 카드 네 개의 상태를 세어 옮긴 것이고 「안전」 같은 종합 판정이 아닙니다. |
| 카드 네 개를 위에서 아래로 가리키기 | 내 PC 상태(CPU·메모리 %, 디스크 여유, 방화벽 켜짐 수), 보안 서버 연결, 최근 위험 신호(최근 24시간 경고·오류 건수), 취약점 조회 | 카드마다 큰 값 하나와 한 줄 설명만 두었고, 측정값만 색을 입혔습니다. |
| 카드 아래 「제로 트러스트 접속 경로 · ZTNA」 | 1 사용자 → 2 기기 상태 → 3 세션 → 4 정책 판정 → 5 업무 앱 다섯 칸. 지금 알 수 있는 칸만 실선과 색으로 채우고, 연결이 없어 비어 있는 칸은 점선과 「대기」「접속 전」 | 업무 앱에 닿기까지 확인하는 순서를 보여 주고, 서버가 판정하는 칸은 연결이 없으면 비워 둡니다. 비어 있음은 이상 없음이 아닙니다. |
| 「지금 조회」 | 버튼이 「조회 중…」으로 바뀐 뒤 마지막 조회 시각이 바뀜 | 조회는 이 버튼으로만 다시 일어납니다. 자동으로 반복하지 않습니다. |
| 「지금 조회」를 한 번 더 | 아래 「조회 추이 · 이 PC 실측」 표에 한 줄 추가, 괄호 안에 바로 전 조회와의 차이 | 추이는 이번 실행 동안 메모리에만 있고, 새로고침하면 사라집니다. |

### 기능 ② 연결·점검 흐름 (약 1분 30초)

| 누를 곳 | 화면에서 보여 줄 것 | 말할 한 문장 |
|---|---|---|
| 보호 현황 아래쪽 계정 연결·AI 연결 칸 (이 화면은 열어도 서버에 자동으로 묻지 않으므로, 시연 전에 「현재 로그인 확인」과 「상태 다시 확인」을 눌러 연결 상태를 먼저 불러옵니다) | 계정 연결과 AI 연결이 끝난 상태 | 계정 연결, AI 연결 승인 순서로 이미 마쳤습니다. 시연에서는 점검만 누릅니다. |
| 「AI 연결 점검」 칸의 「AI 연결 점검」 버튼. AI 연결이 끝나면 AI 연결 줄(「연결 취소」 옆)에 「현재 API 연결 점검」 버튼도 생김(학생 진술). 두 버튼 중 어느 쪽 결과가 아래 표시와 같은지는 시연 전에 눌러 확인 | 「앱 권한 확인 후 점검(verified)」, 모델 수 1, 점검 시각 | 앱 서버를 거쳐 AI 서비스까지 길이 이어져 모델 목록을 받았다는 점검입니다. |
| 같은 결과 아래 문구 | 「모델 목록 응답은 사건 설명 실행이 아닙니다」, 「사건 설명은 아직 실행하지 않았습니다」 | 점검이 성공해도 사건 설명이 성공한 것은 아닙니다. 사건 설명은 보안 기록이 있어야 해서 아직 해 보지 못했습니다. |

### 기능 ③ 정직한 상태 표시 (약 1분 30초)

| 누를 곳 | 화면에서 보여 줄 것 | 말할 한 문장 |
|---|---|---|
| 화면 상단 연결 표시, 대시보드 「보안 서버 연결」 카드 | 「연결 없음」, 「로그인·기기·세션 값 없음 · 이상 없음이 아님」 | 연결이 없으면 정상이나 0건으로 보이지 않고 「연결 없음」이라고 말합니다. |
| 대시보드 「취약점 조회」 카드 | 「준비 안 됨」, 「not_configured · 취약점 없음이 아님」 | 조회하지 않은 것과 취약점이 없는 것은 다르게 보여 줍니다. |

| 「기기·세션 상태 및 알림」 칸의 알림 | 같은 코드·같은 문구의 알림을 한 줄로 묶은 목록, 「알림 N건 · 같은 내용 M종류로 묶음」, 「세부 내역 N건 보기」 | 같은 알림은 한 줄로 묶고, 펼치면 묶기 전 알림이 그대로 나옵니다. |

알림 칸(「학생 상태·알림 표시」)은 보호 현황 화면에서 대시보드 바로 아래에 있습니다(2026-10-28 학생 화면 캡처).

### 시연 중 대체 문장

| 상황 | 말할 문장 |
|---|---|
| 「지금 조회」 후 카드가 「불러오지 못함」으로 나옴 | 조회가 실패했습니다. 이전 값을 그대로 두지 않고 실패라고 표시하는 것이 의도한 동작입니다. 오류 코드는 「자세히 보기」에 있습니다. |
| CPU·메모리·방화벽 중 일부가 「확인 불가」로 나옴 | 이 PC에서 그 값을 읽지 못했다는 뜻입니다. 정상이라는 뜻이 아니어서 확인 불가로 둡니다. 읽지 못한 이유는 「자세히 보기」에 있습니다. |
| AI 연결 점검이 실패하거나 취소됨 | 점검이 성공하지 못했습니다. 화면의 오류 코드와 다음 할 일 문구를 읽고, 이전 성공 결과는 현재 결과가 아니라는 점을 말합니다. |
| 앱이 응답하지 않거나 화면이 이전 모습 그대로임 | 강력 새로고침(`Ctrl+Shift+R`) 후 다시 보여 드리겠습니다. 추이 기록은 새로고침하면 비어 있는 것이 정상입니다. |
| 「연결 없음」이 왜 그대로냐는 질문 | 보안 서버(SDP) 연결은 담당자가 설정해 주어야 하는 부분이어서, 로그인·기기·세션·업무 앱 판정·보안 기록은 실제 값으로 확인하지 못했습니다. |

## 3. 값의 종류 구분

| 종류 | 대상 | 설명 |

### 이 문서를 쓰며 코드와 문서 사이에서 발견한 어긋남

수정하지 않고 기록만 합니다.

- `student/extension.mjs`의 `renderStatus`는 알림을 묶도록 바뀌었지만, 파일 안 1160~1161행 주석은 「renderStatus는 바꾸지 않습니다」라고 적혀 있습니다. 주석이 오래되었습니다.
- `createDashboard`의 `DASHBOARD_VERSION`은 7이고 위쪽 머리말도 「7판」인데, 4ec83af에서 넣은 주석은 「8판」이라고 적습니다. 이 문서는 판 번호 대신 커밋 번호로 구분합니다.
- 대시보드의 「최근 위험 신호」 자세히 보기에는 「앱 알림 N건」을 보이는 줄이 있는데, `renderIdentity`를 감싼 부분이 `notifications`를 넘기지 않아 이 줄은 화면에 나오지 않습니다(학생 캡처의 「자세히 보기」에서 확인: 범위·결과·읽는 법 세 줄만 있음).
- `docs/STUDENT_QUICKSTART.md`는 AI 연결 점검 성공 문구를 「앱 권한 확인 후 모델 응답 점검(verified)」이라고 적지만, 코드의 문구는 「앱 권한 확인 후 점검(verified)」입니다. 같은 문서는 버튼을 「AI 연결 점검」이라고 부르는데, 화면에는 「AI 연결 점검」 칸의 버튼과 연결 완료 뒤 생기는 「현재 API 연결 점검」 버튼이 따로 있고 코드 안내 문구는 후자를 가리킵니다(2026-10-28 학생 캡처와 진술).
- `docs/STUDENT_QUICKSTART.md` 5장은 「조회 추이와 기록」 표라고 하지만 코드의 표 제목은 「조회 추이 · 이 PC 실측」입니다. 또 「이 PC 실측 · 시각」 표시는 값 아래가 아니라 추이 표 제목과 「자세히 보기」 안에 있습니다.
- `docs/STUDENT_RUNBOOK.md`는 0.2.11 기준이고 현재 `package.json`은 0.2.21입니다. 퀵스타트 9장도 이 점을 적고 있습니다.
- `docs/STUDENT_REPRODUCTION_RECORD.md`의 13~21단계 확인표는 2026-10-26 16:24 전후, 계정 연결 이전 시점의 진술입니다. 이후 계정 연결, AI 연결 점검, 13~22단계 통과 결과가 반영되어 있지 않습니다.
- 저장소 루트에 `$null`이라는 이름의 추적되지 않는 파일이 있습니다. 이번 작업에서 만든 파일이 아니며, 커밋 전에 지울지 정해야 합니다.
