# 모몽강 실행 안내 (한 장 요약)

처음 보는 사람이 이 문서 하나만 보고 모몽강을 켜고, 연결하고, 대시보드를 확인할 수 있도록 정리했습니다. 자세한 배경과 문제 해결은 끝에 적은 문서를 봅니다.

- 기준: 시작 틀 `0.2.21`, Windows, Node.js `24.19.0`(실행 도구는 22~24를 허용)
- 앱 주소: `http://127.0.0.1:5189/`
- 실행 이름: 화면에는 「모몽강」으로 보이지만 실행 도구 파일 이름은 `start-alekov.ps1` 그대로 씁니다.

## 1. 준비

PowerShell에서 Node.js가 있는지 확인합니다.

```powershell
node --version
```

`v24.x`가 나오면 됩니다. 명령을 찾을 수 없다고 나오면 https://nodejs.org 에서 Node.js 24를 설치하고 PowerShell 창을 새로 엽니다. 외부 npm 패키지는 쓰지 않으므로 `npm install`은 하지 않습니다.

## 2. 켜기

1. 파일 탐색기에서 저장소 안의 `on-client` 폴더를 엽니다.
2. 주소 표시줄에 `powershell`을 입력하고 Enter를 누릅니다. 줄 앞에 `PS`가 붙은 창이어야 합니다. `PS`가 없으면 명령 프롬프트(cmd)이니 `powershell`을 한 번 더 입력합니다.
3. 아래 명령을 옵션 없이 그대로 실행합니다.

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-alekov.ps1
   ```

4. `브라우저에서 http://127.0.0.1:5189/ 을 여세요`가 나오면 브라우저로 그 주소를 엽니다. 이 창은 앱이 켜져 있는 동안 닫지 않습니다.

처음 실행할 때 실행 도구가 계정 연결용 설정을 이 PC에 자동으로 준비합니다. 설정 파일을 따로 받거나 `-NativeHostConfig` 같은 옵션을 붙이지 않습니다.

## 3. 끄기와 다시 켜기

- 끄기: 앱을 켠 PowerShell 창에서 `Ctrl+C`를 누릅니다.
- 다시 켜기: 같은 `on-client` 폴더에서 2번의 명령을 다시 실행합니다.
- 포트 5189를 다른 프로그램이 쓰고 있다는 안내가 나오면 명령 끝에 ` -Port 5190`을 붙이고 주소도 `:5190`으로 엽니다.

## 4. 계정 연결과 AI 연결 (처음 한 번)

보호 현황 화면 아래쪽 「AI 연결」 칸에서 차례로 진행합니다. 확인 번호·승인 링크·열쇠는 다른 사람에게 보내거나 문서에 적지 않습니다.

1. 「계정 연결 시작」 → 「계정 확인 페이지 열기」로 ALEPH 포털을 열고, 앱에 보이는 6자리 번호를 입력해 확인 → 앱으로 돌아와 「로그인 확인 완료」
2. 「AI 연결 시작」 → 「승인 페이지 열기」로 Workbench 승인 화면을 열고 같은 번호인지 확인한 뒤 승인 → 「승인했으며 연결 확인」
3. 「AI 연결 점검」을 한 번 누릅니다. `앱 권한 확인 후 모델 응답 점검(verified)`이 나오면 AI 연결이 된 것입니다.

AI 연결 점검 성공은 모델이 응답한다는 뜻이고, 보안 사건 설명을 실행했다는 뜻은 아닙니다.

## 5. 모몽강 관제 대시보드 쓰기

보호 현황의 첫 번째 학생 칸 맨 위에 「모몽강 관제 대시보드」가 있습니다.

1. 「지금 조회」를 누릅니다. 자동으로 조회하지 않으므로 볼 때마다 직접 누릅니다.
2. 위쪽 카드 4개를 봅니다.
   - ① 내 PC 상태 요약: CPU·메모리·디스크 여유·Windows 방화벽
   - ② 계정·기기·세션 조회 상태
   - ③ 최근 위험 신호: Windows 기록 최근 24시간 경고·오류 건수
   - ④ 취약점 조회 상태
3. 아래 「조회 추이와 기록」 표에 누를 때마다 한 줄씩 쌓입니다. 괄호 안은 바로 전 조회와 비교한 변화입니다.

값 아래의 「이 PC 실측 · 시각」은 이 PC에서 그 시각에 실제로 잰 값이라는 표시입니다. 대시보드에는 예시 값이 없습니다. 추이 기록은 저장하지 않으므로 새로고침하거나 앱을 다시 켜면 사라집니다.

## 6. 화면을 읽을 때 주의할 점

| 화면 표시 | 뜻 |
|---|---|
| 상단 「연결 없음」, `ENGINE_NOT_CONNECTED` | 기존 보안 서버(SDP)에 연결되지 않은 기본 상태입니다. 로그인·업무 앱·보안 기록 실제 값이 없습니다. 이상 없음이 아닙니다. |
| 「확인 불가」, 「권한 부족」, 「지원 없음」 | 값을 읽지 못한 것입니다. 정상이나 0건으로 읽지 않습니다. |
| Windows 기록 경고·오류 건수 | 침해 판정이 아닙니다. 0건이어도 안전하다는 뜻은 아닙니다. |
| 취약점 「조회 준비 미완료(not_configured)」 | 조회하지 않은 상태입니다. 취약점이 없다는 뜻이 아닙니다. |
| 화면이 이전 모습 그대로 | `Ctrl+Shift+R`로 강력 새로고침합니다. |

## 7. 제공 기능과 학생이 만든 부분

| 구분 | 위치 |
|---|---|
| 제공 기능 | 「내 PC 상태」 카드, 계정·AI 연결 절차, 화면 틀(`public/`), 서버(`src/`), 실행·포장 도구(`tools/`) |
| 학생 작성 | 단계별 표시 함수와 「모몽강 관제 대시보드」(`student/extension.mjs`), 앱 이름·색·배치(`student/appearance.json`) |

## 8. 지금 되는 것과 안 되는 것

| 기능 | 상태 |
|---|---|
| 앱 실행·종료·재실행, 메뉴 이동 | 됨 |
| 내 PC 실측(제공 카드, 대시보드 ①③) | 됨 |
| 계정 연결, AI 연결 점검 | 됨 |
| 로그인·기기·세션, 업무 앱 판정, 보안 기록 | 보안 서버(SDP) 연결이 없어 실제 값 없음 |
| 보안 기록 AI 사건 설명, 보안 조치 | 기록이 없어 실행해 보지 못함 |
| 취약점 조회 | 조회 준비 미완료 |
